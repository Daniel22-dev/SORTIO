# Cross-app review

Adapter shape odpovídá již použité migraci GARP 2.7 v dalších aplikacích AI Studia (např. ACTIVA), ale aplikační kontroly jsou specifické pro SORTIO: žádná generativní AI, explicitně omezený Wikimedia egress, local-first datový trezor, bezpečný JSON backup import a budoucí same-origin live-poll API.

Sdílený GARP core je pouze připnutý referenční strom. SORTIO neimportuje jinou aplikaci ani její bezpečnostní engine.
