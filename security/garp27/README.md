# SORTIO 1.1.21 — GARP 2.7 adapter

Aktivní aplikační bezpečnostní autorita je **GARP 2.7 r2/G-02**. Historický GARP 2.5.1/N5 zůstává zachován jako regresní baseline a release-integrity tooling, nikoli jako konkurenční autorita.

SORTIO nepoužívá generativní AI. Jeho relevantní hranice jsou zejména přístupový guard, local-first data, import/export záloh, Wikimedia Commons egress, service worker/release chain a připravený same-origin live-poll kontrakt.

School-server dependent controls zůstávají rozhodnutím vlastníka **DEFERRED/NOT_TESTED**. Tato migrace nepřidává nové serverové endpointy, Docker/VM konfiguraci ani síťovou infrastrukturu.
