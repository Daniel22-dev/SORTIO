# SORTIO 1.1.8

Datum: 8. 9. 2026

## Změna

- Editor zasedacího plánu je při prvním otevření prázdný.
- Aplikace už sama nepředkresluje souvislé řady.
- Nabídka předloh začíná neutrální volbou „Vyberte předlohu…“; předloha se použije až po výslovné volbě učitele.
- Nový prázdný plán správně hlásí 0 míst.
- Existující uložené zasedací plány se nadále zobrazují podle uloženého tvaru.

## Kompatibilita

Změna nemění datový formát ani algoritmus rozsazování. Jde o UX úpravu výchozího stavu editoru.
